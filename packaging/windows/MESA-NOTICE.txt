Software OpenGL renderer bundled with IngeTrazo for Windows
============================================================

opengl32sw.dll and libgallium_wgl.dll are Mesa's llvmpipe software
rasteriser, as built by the mesa-dist-win project:

  Mesa            https://mesa3d.org            (source: https://gitlab.freedesktop.org/mesa/mesa)
  mesa-dist-win   https://github.com/pal1000/mesa-dist-win  (release 26.1.8, mesa3d-26.1.8-release-msvc.7z)

opengl32sw.dll is Mesa's opengl32.dll, renamed so that Qt uses it when the
graphics driver cannot provide OpenGL 3.3. IngeTrazo does not modify either
file.
